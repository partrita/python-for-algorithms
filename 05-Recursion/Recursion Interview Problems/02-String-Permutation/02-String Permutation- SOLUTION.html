문자열 순열

문제 설명

문자열이 주어지면 재귀를 사용하여 해당 문자열의 가능한 모든 순열 목록을 출력하는 함수를 작성합니다.

예를 들어, s=’abc’인 경우 함수는 [‘abc’, ‘acb’, ‘bac’, ‘bca’, ‘cab’, ‘cba’]를 반환해야 합니다.

참고: 문자가 반복되는 경우 각 발생을 별개로 처리하십시오. 예를 들어 ’xxx’를 입력하면 ’xxx’의 6개 “버전”이 포함된 목록이 반환됩니다.

아래에서 솔루션을 작성하세요.

여기서 우리가 취해야 할 단계는 무엇인지 생각해 봅시다.

  1. 초기 문자열(예: ‘abc’)을 반복합니다.

  • 초기 문자열의 각 문자에 대해 해당 문자를 따로 보관하고 남은 문자열의 모든 순열 목록을 가져옵니다. 예를 들어 현재 반복이 ’b’에 있는 경우 문자열 ’ac’의 모든 순열을 찾고 싶을 것입니다.

  • 2단계의 목록이 있으면 해당 목록의 각 요소를 초기 문자열의 문자에 추가하고 결과를 최종 결과 목록에 추가합니다. 따라서 우리가 ’b’에 있고 목록 [‘ac’, ‘ca’]를 얻은 경우 여기에 ’b’를 추가하여 ’bac’와 ’bca’가 되고 각각을 최종 결과에 추가합니다.

  • 최종 결과 목록을 반환합니다.

계속해서 이것이 구현되었는지 살펴보겠습니다.

def permute(s):
    out = []

    # Base Case
    if len(s) == 1:
        out = [s]

    else:
        # For every letter in string
        for i, let in enumerate(s):
            # For every permutation resulting from Step 2 and 3 described above
            for perm in permute(s[:i] + s[i + 1 :]):
                # Add it to output
                out += [let + perm]

    return out
permute("abc")
['abc', 'acb', 'bac', 'bca', 'cab', 'cba']

솔루션 테스트

    def test(self, solution):

        assert_equal(

        )
        assert_equal(

        )

        print("All test cases passed.")


# Run Tests
t = TestPerm()
t.test(permute)
All test cases passed.

결론

이 문제를 해결하는 데 있어 두 가지 주요 시사점은 다음과 같습니다.

  • i 위치에 새 문자를 넣을 때마다 i+1 위치에서 가능한 모든 조합을 찾아야 했습니다. 이것이 우리가 수행한 재귀 호출이었습니다. 문자열을 언제 저장해야 하는지 어떻게 알 수 있나요? 입력 문자열의 문자 수보다 큰 i 위치에 있으면 문자열의 유효한 순열 하나를 찾았다는 것을 알고 이를 목록에 추가하고 i보다 작은 위치의 문자 변경으로 돌아갈 수 있습니다. 이것이 기본 사례였습니다. 재귀를 사용할 때는 항상 재귀 사례와 기본 사례가 있어야 한다는 점을 기억하세요!

  • 이 문제의 또 다른 큰 부분은 주어진 위치에 어떤 글자를 넣을 수 있는지 알아내는 것이었습니다. 샘플 문자열 “abc”를 사용하여 첫 번째 문자가 “c”인 모든 순열을 통과한다고 가정해 보겠습니다. 그러면 두 번째와 세 번째 위치의 문자는 “a”가 이미 사용되었기 때문에 “a” 또는 “b”만 될 수 있다는 점을 분명히 해야 합니다. 알고리즘의 일부로, 주어진 위치에 어떤 문자를 사용할 수 있는지 알아야 합니다. 이전 위치에 사용된 문자를 재사용할 수 없기 때문입니다.
